# Welcome, to _The Game_

> This is my first semi-serious project in C/C++. The goal is to experiment, have fun, and reach enlightenment!

_The Game_ is still in a conceptual phase, meaning I don't know what the f___ I'll be building in terms of theme. The only things I know for a fact for now are:
- It will be simple
- It will be 2D
- It will use a graphical library/framework like SDL or Raylib
- It will not be pretty
- It will probably not be fun to play, but will be _playable_

Some ideas come to mind when thinking of a game genre:
- A platformer
- A physics based simulation
- A top-down view shooter-like
- _TBD_

Thinking ahead, the first weeks will probably be filled with bugs and issues, and as such, no presentable version will be released. The plan is to make (force) the reader to play the game, and have them leave positive feedback to feed the ego and thus feed my drive to continue experimentation in C/C++ games.

Once I feel this project has reached its peak, I will probably move on to 3D game programming. I will not be using pre-built engines. If anything, it will be my final project in this series.
